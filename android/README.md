# 글 강화기 Android v0.5.0

Android 8.0(API 26) 이상에서 동작하는 네이티브 Kotlin 오버레이 앱입니다.

## 다음 버전: 기본 복사·붙여넣기 메뉴, 다른 앱의 선택 메뉴

- 입력창을 길게 누르면 다른 앱과 같은 Android 기본 메뉴(복사·붙여넣기·전체 선택 등)가 뜹니다.
  기존 `⋯` 편집 메뉴 버튼도 그대로 둡니다.
- 다른 앱에서 글을 선택하면 나오는 메뉴(필요하면 `⋮ 더보기`)에 두 항목이 생깁니다.
  - `글 강화`: 작은 창에서 바로 강화하고 결과를 기록에 남깁니다. 카카오톡 입력창처럼 고칠 수
    있는 칸이면 `바꾸기`로 선택한 글을 강화된 글로 바꿉니다. `복사`, `다시 강화`,
    `글 강화기에서 열기`(버블 창에서 이어서 다듬기)도 있습니다.
  - `글 강화기 채팅`: 선택한 글을 따옴표로 묶어 사이드 채팅 입력칸에 넣고 엽니다.
  - 버블이 꺼져 있었다면 함께 켭니다. 메뉴 위치와 표시 방식은 앱마다 조금 다릅니다.

## 0.6.0 답변 스트리밍·문장 출처·요청 분류

- 답변이 쓰는 대로 말풍선에 나타납니다. 다른 AI로 다시 물으면 앞서 보인 글을 지웁니다.
- 근거 문장에는 밑줄과 출처 번호가 붙습니다. 누르면 `출처 확인` 창에서 문장·사이트·
  주소·찾은 검색어를 보여 주고, `확인`을 눌러야 브라우저로 엽니다. `취소`·뒤로 가기·
  바깥 터치로 닫습니다. 답변 아래 출처 목록도 같은 창을 거칩니다.
- 답변마다 `앱 조작`·`웹 조사`·`글 상담`(출처 없는 조사는 `질문 답변`) 이름표가 붙습니다.
- 검색어·출처 기록을 후속 질문에 넘겨 같은 검색을 줄입니다.
- 사이드 채팅 화면을 `overlay/SideChatScreen.kt`, 답변 처리를 `ai/ChatAnswer.kt`,
  스트리밍 해석을 `ai/SideChatStream.kt`로 나눴습니다. 답변 처리 규칙은 Windows와
  같은 공통 사례로 검사합니다.

## 0.5.0 검색·사이드 채팅 개선

- 검색 답변 뒤 후속 질문에서 이전 대화가 잘리던 문제를 고쳤습니다.
- 주제어·화면 첨부 기반 검색 강제를 없애고 직접 요청·`⌕ 검색` 버튼·후속 탐색만
  검색을 강제합니다. 출처가 없으면 오류 대신 경고 표시와 함께 답변을 보여 줍니다.
- 외부 자료가 섞인 대화의 기능 명령은 적용 확인 카드를 거쳐 실행합니다.
- 답변 대기 중 진행 단계·경과 시간과 `중단` 버튼을 표시하고, 중단하면 연결을 끊습니다.

## 0.4.3 모바일 UI 정돈

- 입력·결과·사이드 채팅·설정·시작 화면을 차콜 배경과 보라색 강조색으로 통일했습니다.
- 상단 동작은 설명이 있는 선형 아이콘, 입력 주요 동작은 균형 잡힌 한 줄 버튼으로 정리했습니다.
- 배경 불투명도를 바꿔도 본문과 입력 영역은 흐려지지 않습니다.
- 채팅의 간단한 굵은 글씨·제목·코드를 네이티브 텍스트로 표시하며 선택 복사는 표시된 글 기준입니다.
- 키보드가 없는데 작은 팝업 하단을 키보드로 오인하던 배치 문제와 버튼 겹침을 보완했습니다.
- PC 버전과 AI 생성·검색 요청, 저장 데이터 형식은 변경하지 않았습니다.

검수 범위와 화면은 `../docs/MOBILE-UI-0.4.3.md`를 참고하세요. 기존 0.4.2 APK는
`releases/0.4.2/WritingEnhancer-debug.apk`에 보존되어 있습니다.

## 실행

1. Android Studio에서 이 폴더를 엽니다.
2. `app`을 기기에 설치합니다.
3. 우측 상단 `⚙`에서 OpenAI API 키와 선택 사항인 Gemini API 키를 저장합니다.
4. `버블 시작`을 누르고 Android의 `다른 앱 위에 표시` 권한을 허용합니다.

버블은 화면 어디든 자유롭게 옮길 수 있습니다. 길게 누르면 아래에 종료 영역이
나타나며, 그곳에 놓으면 서비스가 종료됩니다. 열린 강화기는 바깥 터치나 상단 `×`로
다시 버블 상태로 접힙니다. 뒤로가기는 키보드·중첩 화면을 먼저 닫고, 최상위
입력/결과 화면에서만 초안을 보존한 채 버블로 접습니다. 뒤로가기로 서비스가
종료되지는 않습니다.

## 작성 보조

- 글 재료 앞에 상황이나 용도를 한 줄 적을 수 있습니다.
- 이미지·PDF·TXT·MD·CSV·JSON 파일과 현재 화면을 첨부할 수 있습니다.
- 첨부는 최대 5개, 파일당 8MB, 전체 12MB로 제한합니다. 텍스트 파일은 UTF-8로
  안전하게 읽어 파일당 16,000자·전체 28,000자까지만 AI에 전달합니다.
- 이미지·PDF는 확장자나 MIME뿐 아니라 실제 파일 시그니처까지 확인합니다. 파일명은
  제어·양방향 문자를 제거하고 80자로 제한하며, Gemini 직렬화 요청은 19MiB 미만,
  OpenAI 요청은 24MiB 미만으로 최종 검사합니다.
- `알아맞춰 봐`는 글을 만들기 전에 결과에 가장 중요한 질문 하나만 먼저 합니다.
- 첫 화면에는 원문 작성 영역만 기본 노출합니다. 선택 입력인 상황과
  파일·현재 화면·말하기 도구는 각각 작은 버튼을 눌렀을 때만 펼쳐집니다.
- 5단계 `강화 범위`의 중앙은 `원문 충실`입니다. 왼쪽은 목표 분량
  45~85%의 요약·정리, 오른쪽은 120~200%의 내용 보완·확장으로 동작하며
  구체적인 분량 요구가 없을 때만 요청마다 계산한 목표 글자 수도 AI에 전달합니다.
  사용자가 줄 수·문장 수·문단 수·배수·글자 수를 직접 지정하면 그 분량을
  최우선으로 적용하고, 문체·구조 지시도 기본 강화 규칙보다 우선합니다. 모든
  단계와 사용자 요구에서 이름·인물·날짜·시간·금액·숫자·장소·약속·완료 여부·
  원인·관계·부정처럼 입력에 없는 사실은 새로 만들거나 추정하지 않습니다.
- 원문과 후속 답변은 입력량에 따라 늘어나고, 상한 이후에는 내부에서 스크롤됩니다.
- 패널과 설정을 열 때 키보드는 자동으로 나타나지 않습니다. 입력칸을 직접 누를 때만
  열리며, 키보드가 열린 동안 입력칸과 주요 버튼까지 스크롤해 접근할 수 있습니다.
- 입력칸은 손을 뗄 때까지 이동량을 확인해 명확한 탭에서만 키보드를 엽니다.
  스와이프·슬라이드·스크롤은 입력 활성화로 처리하지 않습니다.
- 길게 누르기는 Android 기본 텍스트 선택에 맡겨 선택 영역과 핸들이 유지됩니다.
  작은 `⋯` 버튼이나 활성화된 커서 핸들을 누르면
  `붙여넣기·되돌리기·복사·잘라내기·전체 선택` 메뉴가 입력칸 아래에 나타납니다.
- 같은 `⋯` 버튼을 다시 누르면 편집 메뉴가 접힙니다. 뒤로가기로 키보드를 닫아도
  메뉴의 펼침 상태는 바뀌지 않습니다. 이 편집 메뉴는 원문에만 제공하며 상황과
  추가 질문에는 노출하지 않고, 추가 질문에는 별도 음성 입력 버튼도 두지 않습니다.
- 결과 화면의 `다시 강화`는 원문 보기 왼쪽의 `↻`, 이전·다음은
  `완성된 글 1/N` 줄 오른쪽의 아이콘 둘로 표시합니다. `↻`은 기존 설정을
  유지하되 현재 결과와 AI 추론은 참조하지 않고 원문에서 새 버전을 만듭니다.
- AI 제안 옆의 `예`와 직접 요구 옆의 `반영하기`는 현재 결과에서 이어서 새
  버전을 만듭니다. 직접 요구를 입력하면 AI 제안 영역을 어둡게 하고 `예`를
  비활성화해 직접 입력을 우선합니다.
- `다시 강화`, `반영하기`, `예`를 누르면 별도 로딩 아이콘 대신 해당 버튼 안에
  생성 상태를 표시합니다. 처리 중에는 모든 생성 버튼을 잠가 중복 요청을 막고,
  완료·실패 뒤 원래 버튼 상태를 복원합니다.
- 상단 로고·메뉴, 스크롤 가능한 내용, 하단 주요 동작을 분리해 상단과 핵심
  버튼을 고정 노출합니다. 창의 너비·높이에 따라 바깥 여백, 입력 최대 줄 수,
  결과 영역과 버튼 높이를 compact·regular·spacious 단계로 조정합니다.
- 주요 창과 설정은 상단을 끌어 이동하고 우하단 크기 조절 아이콘을 끌어 크기를 바꿀 수 있는
  팝업입니다. 일부가 화면 밖으로 나가도록 둘 수 있고 설정에서 투명도를 조절합니다.
- 파일·현재 화면·음성 입력은 사용자가 버튼을 눌렀을 때만 시스템 권한 화면을 엽니다.
- 화면 캡처 순간에는 강화기 오버레이를 숨기며, 캡처 한 장 뒤 MediaProjection
  foreground service가 즉시 끝납니다.
- `강화한 글 복사`, 다시 강화, 이전·다음 결과 탐색을 지원하며 양 끝에서는
  해당 탐색 버튼이 비활성화됩니다.
- `알아맞춰 봐`의 질문·상황 추론·작성 중인 답도 암호화 임시 저장되어 패널이나
  서비스를 닫았다 다시 열어도 질문 화면 그대로 이어집니다.
- 첫 완성 뒤 질문은 완성된 글의 유형·주제·목적을 먼저 예상하고, 그 목적에 맞춰
  내용·구조·어조를 더 다듬어도 되는지 묻습니다. 두 번째부터는 적용한 추천 판단과
  다음 수정 방향을 묻습니다. 후속 입력 안내는 `아니면 다른 요구 사항 입력`입니다.

## 사이드 채팅 베타

- 모든 글 강화기 화면의 최상단에서 `기록` 바로 오른쪽에 있는 채팅 아이콘으로 엽니다.
  기존 `＋ 도구` 안의 채팅 버튼은 제거하고 파일·화면·말하기만 남겼습니다.
- 모바일에서는 별도 오버레이를 겹치지 않고 현재 팝업 안의 독립 화면으로 전환합니다.
- 현재 상황·원문·결과·후속 요구·강화 범위·결과 버전·첨부 이름을 매 요청에
  연결하고, 사용자가 명시적으로 요청한 강화기 기능만 실행합니다.
- 원문·상황·결과 반영, 완성·재강화, 강화 범위 변경, 결과 이동, 복사와
  기록·설정·도구 화면 열기를 지원합니다. 파일·화면·음성·기억 승인은 관련
  화면까지만 열고 사용자의 권한 선택을 대신하지 않습니다.
- 채팅의 재강화도 현재 결과를 제외하고 원문과 기존 설정으로 새 버전을 만들며,
  채팅에서 결과를 반영해도 기존 버전을 덮어쓰지 않고 새 버전으로 추가합니다.
- 사이드 채팅에서 `×`로 접으면 다음 버블 터치 때 사이드 채팅으로 돌아오고,
  글 강화기에서 `×`로 접으면 다음 버블 터치 때 글 강화기로 돌아옵니다. 이 마지막
  화면 상태는 서비스가 다시 시작되어도 유지됩니다.
- 새 채팅 `＋`는 화면 최상단 `글로` 바로 왼쪽에 표시합니다. 사용자 메시지의
  수정 아이콘은 말풍선 왼쪽, AI 답변의 복사 아이콘은 말풍선 오른쪽에 표시하며 복사해도
  채팅 화면과 대화 상태는 그대로 유지됩니다.
- AI 답변 본문은 길게 눌러 필요한 부분만 선택·복사할 수 있습니다. 채팅 입력과
  메시지 수정 입력은 Android 기본 붙여넣기·복사·잘라내기 메뉴를 그대로 사용합니다.
- 사용자 메시지의 `수정`을 누르고 완료하면 그 메시지 이후 응답을 모두 제거하고
  수정문부터 바로 다시 답합니다.
- `새 채팅`은 채팅 기록만 지우며 초기화 직후 입력칸을 다시 사용할 수 있습니다.
  채팅 화면을 처음 열거나 초기화했을 때 키보드를 강제로 표시하지는 않습니다.
- 최근 60개 메시지를 글 히스토리·기억과 분리해 Keystore 기반으로 암호화하고,
  AI에는 최근 20개·최대 24,000자만 전달합니다.
- 최신 정보·사실 확인·비교·추천·정책처럼 외부 정보가 필요한 질문에서는 모델이
  검색 여부를 판단하고, 검색할 때는 질문의 판단 축을 하위 주제로 나눠 여러 번
  검색한 뒤 결론과 핵심 차이를 종합합니다. 답변 아래 출처는 `웹에서 확인 · 출처 N개`로 접어 두고, 펼쳤을
  때 제목과 도메인을 짧은 목록으로 최대 6개 표시합니다(실제 인용한 출처가 앞).
  긴 원시 URL은 답변에서 제거하고 문장 링크와 출처 목록으로만 제공합니다.
  출처를 누르면 확인 창을 거쳐 검증된 `http`·`https` 주소만 기본 브라우저로 엽니다.
- 단순 글쓰기·앱 기능·현재 작성 중인 글에 관한 요청은 웹 검색으로 보내지 않으며,
  `검색하지 말고`처럼 사용자가 명시적으로 금지하면 검색 도구 자체를 사용하지
  않습니다.
- `검색해 줘·찾아줘·사실 확인·출처와 함께`와 대응하는 영문 표현, 작성 도구 줄의
  `⌕ 검색`(다음 질문 한 번), `이어서 탐색` 질문만 검색을 강제합니다. 출처를 받지
  못하면 `웹 출처를 확인하지 못한 답변`
  표시와 함께 보여 줍니다.
- 검색·화면 자료가 섞인 대화에서 AI가 내용을 바꾸는 동작을 제안하면 변경 미리보기와
  `적용`/`취소` 카드를 보여 주고, `적용`을 누를 때만 실행합니다. 화면 이동 동작은
  바로 실행합니다. 이전 대화는 외부 자료 여부와 관계없이 그대로 이어 받습니다.
- 답변을 기다리는 동안 진행 단계와 경과 시간을 표시하고, 보내기 버튼이 `중단`으로
  바뀝니다. 중단하면 진행 중인 연결을 끊고 입력을 입력칸에 되돌립니다.
- 검색 근거가 있는 답변에는 최대 3개의 `이어서 탐색` 질문을 표시합니다. 누르면
  키보드를 새로 띄우지 않고 다음 검색을 바로 시작합니다. 앱 기능 실행이나 검색
  근거가 없는 답변에는 이 질문을 표시하지 않습니다.
- 채팅 입력부의 `화면`을 누르면 매번 Android 화면 공유 동의를 받은 뒤 한 장만
  촬영하고, `이미지`를 누르면 기기의 이미지 파일을 선택합니다. 둘 다 전송 전에
  실제 썸네일을 표시하며 `영역 선택`에서 필요한 부분만 드래그해 확정할 수 있습니다.
  해당 이미지는 다음 질문 한 번에만 이미지 맥락으로
  전송되고, 웹 검색은 필요할 때 함께 사용합니다. 검색을 명시적으로 금지하면
  웹 없이 화면만 분석합니다. 채팅 기록·글 첨부·기억에는 저장하지 않고
  답변 성공·실패·중단과 관계없이 사용 직후 내부 임시 파일을 삭제합니다.
  화면 이미지는 첫 번째로 선택된 AI 공급자에만 보내고, 실패해도 다른 공급자로
  재전송하지 않습니다.

## 로컬 상태

- 작성 중인 상황·원문·후속 답변·첨부 목록은 자동 임시 저장됩니다.
- 선택한 강화 범위는 초안과 각 결과 버전에 함께 저장되며, 이전·다음 결과를
  오갈 때 해당 결과에 사용한 단계도 복원됩니다. 구버전 데이터는 기본 3단계로
  호환됩니다.
- 텍스트 상태는 Keystore 기반으로 암호화하며 첨부 원본은 다른 앱이 읽을 수 없는
  앱 전용 내부 저장소에 복사합니다.
- 첨부를 제거하거나 새 글/히스토리를 삭제하면 draft와 다른 히스토리가 참조하지
  않는 앱 전용 첨부 파일만 정리하며, 서비스 시작 때 전달 중단으로 남은 orphan도
  한 번 더 정리합니다.
- 이전 작업은 최대 40개, 작업별 결과는 최대 12개까지 보관하며 항목별 삭제가 가능합니다.
- 기록 카드에는 최종 결과와 함께 해당 작업의 최초 원문도 표시하고 저장합니다.
- 설정에서 기억을 직접 보고 수정하거나 개별/전체 삭제할 수 있습니다.
- 버블 크기는 설정에서 44~84dp로 조절할 수 있습니다.

기본 호출은 `gpt-5.6-terra`이며, 연결 실패·응답 형식 오류 때
`gemini-3.6-flash`로 한 번 폴백합니다. 사용자는 모델을 고르지 않습니다.
두 공급자 request body에는 모두 `store: false`를 명시합니다.

## 개인정보와 기억

- API 키와 기억 카드는 Android Keystore의 AES-GCM 키로 기기 안에 암호화됩니다.
- 사이드 채팅 기록도 같은 방식으로 기기 안에 암호화됩니다.
- 원문 전체는 장기 기억하지 않습니다.
- 한 요청에서 최대 3개의 후보만 검토하고 전체 50개, 호출당 관련 기억 5개로 제한합니다.
- 기억 후보는 결과 뒤 사용자에게 먼저 보여 주며 `기억에 추가`를 명시적으로
  선택한 경우에만 저장합니다. 설정의 `기억 추가 비활성화`로 새 저장을 완전히 끌 수 있습니다.
- 추론 기억은 8시간짜리 세션 기억이며 반복 확인 전에는 장기 기억으로 승격하지 않습니다.
- 연락처, 이메일, 인증정보, 금융·신분·의료 정보는 기억 후보에서 차단합니다.
- 추가 후 `취소` 또는 설정의 `기억 지우기`로 제거할 수 있습니다.
