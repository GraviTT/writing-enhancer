# Android 0.4.3 · 모바일 UI 정돈

## 범위와 판단

`skill-library`로 현재 Kotlin 네이티브 앱과 기존 테스트·설치 산출물을 확인했습니다.
지금 단계에는 별도 이미지 생성이나 웹 목업보다 실제 Android 화면 수정과 검수가 적합하므로
추가 스킬 설치 없이 진행했습니다. 커뮤니티 스킬은 설치하거나 실행하지 않았습니다.
PC 0.4.2와 AI 생성/검색 요청·프롬프트·기억/히스토리 데이터 형식은 그대로입니다.

## 변경점

- 차콜/라벤더 색상, 둥근 표면, 얇은 테두리, 일정한 글자 크기·간격·터치 피드백.
- 기록/채팅/설정/닫기 등은 설명·툴팁이 있는 네이티브 선형 아이콘, 주요 아이콘 터치 영역 44dp.
- 입력을 먼저 배치하고 상황·도구·편집은 그 아래에 유지. 주 동작 두 개는 한 줄 균등 정렬.
- 작은 팝업에서는 안내 문구를 줄이고 작성 영역을 우선. 결과의 새 글 버튼은 원문 도구 줄로 통합.
- 채팅 답변 폭 확대, 간단한 굵은 글씨/제목/코드 표시, 출처 접기와 후속 제안의 밀도 조정.
- AI 답변 부분 복사 시 화면에 표시된 문자열을 기준으로 선택 오프셋 계산.
- 설정 헤더 고정, AI 연결 설정 접기, 화면/기억 구분. 배경 불투명도만 바꾸고 내용은 선명하게 유지.
- 시작 화면에도 같은 디자인과 예시 문장 적용. 시스템 상·하단 영역과 겹치지 않도록 inset 반영.
- Android 11 이상에서는 실제 키보드 inset을 사용해 팝업 아래 빈 공간을 키보드로 오인하지 않도록 수정.
  하단 버튼을 단순히 위에 덧그리지 않고 레이아웃 공간을 확보해 편집 영역과 겹침 방지.

## 검수

- `assembleDebug`, `assembleDebugAndroidTest`, `testDebugUnitTest`, `lintDebug`.
- 단위 테스트 65개 통과, lint 오류/경고 없음.
- 별도 Android 15/API 35 에뮬레이터에서 설치·시작·버블 열기와 네이티브 화면 확인.
- 280×360dp 입력: 원문 입력과 고정 주요 버튼 노출 확인.
- 380×720dp 결과: 원문/다시 강화/슬라이더/제안/직접 요구와 복사 동작 배치 확인.
- 320×560dp 채팅, 시스템 글꼴 130%: 상단 `글로`와 고정 입력/보내기 표시 확인.
  본문은 세로 스크롤, 후속 제안은 가로 스크롤로 접근합니다.
- 입력칸 직접 탭 후 키보드 표시, 요구 입력과 반영하기/복사 버튼이 키보드 위에 남는 것 확인.
- 출처 펼침/접힘 및 설정의 AI 연결 영역 펼침/접힘 확인.
- 채팅 답변에서 굵게 표시된 `핵심을`만 길게 눌러 선택 → 답변 복사 아이콘 → 채팅 편집 메뉴의
  붙여넣기 순서로 정확히 같은 부분 문자열이 입력되는 것을 확인. 이어서 전체 선택 → 잘라내기도 통과.
- 네이티브 instrumentation: 굵은 글씨 span, 코드 문자 보존, 선택 부분 문자열, 배경 투명도와 view alpha 분리 검증.
- 검수 후 Android crash 버퍼에 기록 없음. 최종 배포 APK의 에뮬레이터 업데이트 설치 성공.

검수용 대화와 결과는 명시적인 예시 데이터이며 실제 AI 응답이 아닙니다. API 키 없이 검수해
비용이 발생하는 생성/검색을 호출하지 않았습니다. 스크린샷은 `android/device-qa/ui-0.4.3/`에 있습니다.
재현 도구 `android/scripts/qa-mobile-ui.ps1`과 테스트 APK의 fixture는 전용 에뮬레이터에서만 실행하도록
제한되어 있으며 일반 설치 APK에는 테스트 코드가 포함되지 않습니다.

## 설치 및 남은 확인

- 설치 파일: `android/WritingEnhancer-0.4.3-debug.apk` (versionCode 9).
  `android/WritingEnhancer-debug.apk`도 같은 파일로 갱신했으며 SHA-256은 루트 `CHECKSUMS.sha256`에 기록했습니다.
- 이전 안정 APK는 `android/releases/0.4.2/`에 별도로 보존.
- 이 작업 시점에는 실제 휴대폰이 연결되어 있지 않아 실기기 설치는 하지 않았습니다.
- Samsung One UI의 실제 키보드/기본 선택 메뉴, Android 8~10 폴백 경로, 시스템 최대 글꼴 크기,
  실제 화면 캡처 권한·카메라/파일 선택·AI 응답 품질은 이번 UI 검수 범위 밖입니다.
