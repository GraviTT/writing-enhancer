# 글강화기

생각나는 대로 입력하면 먼저 완성된 글을 보여주고, 그다음 AI가 한 가지 질문으로 결과를 더 정확하게 다듬는 상시 대기형 글쓰기 도구입니다.

## 제품 원칙

1. 완성 먼저, 질문은 나중에.
2. 사용자는 재료만 제공하고 판단은 AI가 한다.
3. 사용자가 고르지 못하면 `알아서`가 기본 답이다.
4. 이름, 날짜, 금액, 약속, 부정 표현은 임의로 바꾸거나 만들지 않는다.
5. 원문 대신 다음 판단을 바꿀 최소한의 기억만 저장한다.
6. 한 화면에는 한 개의 주요 행동만 둔다.

## 구성

- `desktop/` — Windows용 반투명 사이드 패널
- `android/` — Android용 플로팅 버블
- `shared/` — 공통 출력 계약, 프롬프트, 메모리 정책과 테스트
- `docs/` — 제품·동작 명세

두 앱 모두 GPT-5.6 Terra를 기본 모델로 사용하고, 기술적 장애가 발생할 때만 Gemini 3.6 Flash로 한 번 폴백합니다. API 키는 소스 코드에 포함하지 않고 각 앱의 작은 설정 팝업에서 입력합니다.

## 기본 흐름

```text
버블/손잡이 누르기
  → 필요하면 상황·참고 자료 추가
  → 아무렇게나 입력
  → 완성본
  → 강화한 글 복사
  → AI의 짧은 질문
  → 답변 또는 "알아서"
```

AI가 먼저 질문해야 더 정확할 때는 사용자가 `알아맞춰 봐`를 누를 수 있습니다.
이 경우에도 한 번에 가장 중요한 질문 하나만 보여 주고, 사용자가 `알아서`를
누르면 AI의 추천 판단으로 바로 완성합니다.

상황과 파일·화면·말하기 도구는 기본 화면에서 접어 두며, 모델 선택과 문체
목록은 일반 화면에 노출하지 않습니다.

## 편의 기능

- 상황 메모, 파일·이미지 첨부, 현재 화면 첨부
- 본문과 후속 답변 음성 입력
- 작성 중인 본문·상황·답변 자동 저장과 다음 실행 시 복원
- 작업별 히스토리, 개별 삭제, 재강화, 이전·다음 결과 버전
- 원문 충실도와 AI 보완 수준을 조절하는 결과별 5단계 강화 범위
- 원문과 결과를 함께 보여 주는 기록
- 사용자 승인 뒤에만 추가되는 기억과 새 기억 추가 비활성화
- 저장된 기억 확인·수정·삭제
- 첨부 개수·크기·형식 상한과 민감정보 기억 차단
- 현재 글과 기능을 연동하는 플랫폼별 `사이드 채팅` 베타

화면 첨부는 사용자가 누른 순간에만 작동하며 촬영 직전 강화기 UI를 숨깁니다.
마이크와 화면 캡처도 상시 사용하지 않고 기능을 직접 누른 경우에만 권한을
요청합니다.

## 개발 상태

Windows와 Android 앱이 모두 구현되어 있습니다.

### Windows

1. [`desktop/dist/Writing-Enhancer-0.5.0-portable.zip`](desktop/dist/Writing-Enhancer-0.5.0-portable.zip)을 풉니다.
2. 폴더 안의 `글 강화기.exe`를 실행합니다.
3. 작은 톱니 버튼에서 OpenAI 또는 Gemini API 키를 입력합니다.

접힌 손잡이, 펼친 패널, 설정·기록 팝업 제목을 드래그할 수 있습니다. 우하단
손잡이로 크기를 조절하고, 자유 이동 모드에서는 다시 잡을 가장자리를 남긴 채
화면 일부 밖에도 둘 수 있습니다. 설정에서 가장자리 고정 또는 자유 이동,
왼쪽·오른쪽 배치, 55~100% 투명도, 글자 크기, 창 크기를 조절할 수 있습니다.

상단의 `β` 말풍선이나 트레이 메뉴에서 PC `사이드 채팅` 베타로 전환할 수
있습니다. 글 강화기와 채팅은 한 번에 하나만 보이고 `글로`로 서로 전환하며,
최소화와 창 밖 클릭 시 자동 접기를 지원합니다. 채팅 기록은 별도 파일에 저장하지만 현재 작성 중인
상황·원문·결과를 인식하며, 명시적인 요청은 글 강화기 기능으로 연결할 수
있습니다. 사용자 메시지를 수정하면 그 뒤의 기존 대화를 제거하고 다시 답합니다.
채팅에서 결과 반영을 요청하면 현재 결과를 덮어쓰지 않고 새 결과 버전으로
남기며, 재강화는 현재 결과가 아닌 원문과 기존 설정에서 다시 시작합니다.
사이드 채팅 상단에서 새 채팅을 시작할 수 있고, 사용자 메시지 왼쪽의 `수정`과
AI 답변 오른쪽의 `복사` 버튼으로 대화를 바로 편집·복사할 수 있습니다.
사이드 채팅의 웹 검색과 적용 규칙은 아래 [검색과 적용 확인](#검색과-적용-확인-050)에
정리했습니다. 화면 캡처나 이미지 첨부 뒤에는 전송 전 미리보기가 나타나며, 필요한
부분만 드래그해 선택한 뒤 다음 질문 한 번에만 함께 보냅니다. 화면 이미지는 채팅
기록이나 글 첨부로 저장하지 않고, 요청이 실패해도 같은 이미지를 다른 AI로
재전송하지 않습니다.

PC의 결과 생성도 직접 입력한 상황·문체·구조·목적을 기본 강화 규칙보다 먼저
적용합니다. 줄·문장·문단·배수·글자 수처럼 구체적인 분량 요구는 강화 범위보다
우선하며, 이름·날짜·수치·장소·관계·확정 여부 등은 사용자 제공 정보 밖에서
추정하지 않습니다.

설치 프로그램이 아닌 서명되지 않은 휴대용 빌드이므로 Windows가 확인 화면을
표시할 수 있습니다.

### Android

1. [`android/WritingEnhancer-debug.apk`](android/WritingEnhancer-debug.apk)를 기기에 설치합니다.
2. 앱의 설명을 확인한 뒤 `화면 위에 표시` 권한을 허용합니다.
3. 작은 톱니 버튼에서 OpenAI 또는 Gemini API 키를 입력하고 `버블 시작`을 누릅니다.

버블은 원하는 위치에 자유롭게 둘 수 있습니다. 길게 누르거나 끌면 아래에
종료 영역이 나타나며 그곳에 놓으면 서비스가 종료됩니다. 패널을 열 때 키보드는
자동으로 나타나지 않고 입력칸을 직접 눌렀을 때만 열립니다. 뒤로가기는 키보드,
기록·질문 화면을 먼저 닫고 최상위 화면에서만 패널을 버블로 접으며 서비스를
종료하지 않습니다. 첫 화면은 원문 작성 영역만 남기고 상황·파일·화면·말하기를
작은 접이식 버튼에 넣었습니다. 스크롤과 탭을 구분하고 길게 누른 기본 선택을
유지하며, 원문에서만 `⋯` 또는 커서 핸들로 편집 메뉴를 엽니다. 상황·추가 질문에는
별도 편집 메뉴와 음성 버튼을 노출하지 않습니다. 결과 화면에서는 재강화를 작은
`↻` 아이콘으로, 결과 이동을 버전 줄 오른쪽의 아이콘 둘로 표시합니다. AI 제안은
`예`, 직접 요구는 `반영하기`로 나눠 현재 결과에서 이어서 다듬으며, 직접 요구를
입력하면 AI 제안과 `예`가 어두워지고 잠깁니다. `↻`은 이전 결과를 참조하지 않고
같은 설정과 원문으로 새 결과를 만듭니다.
`다시 강화`, `반영하기`, `예` 실행 중에는 누른 버튼 자체가 생성 상태로 바뀌고
나머지 생성 버튼이 잠깁니다.
주요 동작은 창 아래에 고정되어 작은 창에서도 사라지지 않으며, 창 크기에 따라
입력 줄 수·결과 높이·여백이 함께 조절됩니다. 주요 창은 이동·크기 조절과 부분
화면 밖 배치가 가능하고 설정에서 투명도를 바꿀 수 있습니다. 상단 로고·메뉴는
콘텐츠를 스크롤하거나 창 크기를 바꿔도 고정됩니다.

PC에서 먼저 도입한 `사이드 채팅 β`도 모바일에 맞게 같은 오버레이 안의 독립
화면으로 제공합니다. 모든 글 강화기 화면의 최상단 `기록` 오른쪽에 있는 `β`
버튼으로 열며, 현재 원문·상황·결과·후속 요구·강화 범위를 인식합니다. 메시지를
수정하면 그 지점 이후 대화를 제거하고 바로 다시 답하며, 새 대화 뒤에도 입력칸을
다시 사용할 수 있습니다. 채팅 기록은 글 기록·기억과 분리해 기기 안에 암호화합니다.
사이드 채팅에서 X로 접으면 다음 버블 터치도 채팅으로, 글 강화기에서 X로 접으면
다음 버블 터치도 강화기로 복원됩니다. 채팅 재강화는 원문 기준 새 버전으로,
결과 반영은 기존 결과를 덮지 않는 새 버전으로 처리합니다.
모바일의 `새 채팅`은 최상단 `글로` 바로 왼쪽에 있으며, 사용자 메시지 왼쪽에는
`수정`, AI 답변 오른쪽에는 `복사` 버튼을 표시합니다.
모바일 사이드 채팅도 PC와 같은 [검색과 적용 확인](#검색과-적용-확인-050) 규칙을
따르며, 작성 도구 줄의 `⌕ 검색`, 보내기 자리의 `중단`, 적용 확인 카드를 제공합니다.
`화면`을 누르면 Android의 화면 공유 동의를 받은 뒤 화면 한 장을 준비하고,
`이미지`는 기기 파일을 선택합니다. 두 이미지 모두 전송 전에 미리보기와 부분 선택을
지원하며 캡처가 끝나면 사이드 채팅으로 돌아옵니다. 화면 임시 파일은 요청
성공·실패·중단과 관계없이 삭제합니다.

디버그 서명 APK이므로 일반 앱 스토어 배포용은 아닙니다.

## 검색과 적용 확인 (0.5.0)

Windows와 Android 사이드 채팅에 같은 규칙을 적용합니다.

- **이어지는 질문의 맥락 유지.** 검색 답변 뒤에 `그럼 갤럭시는?`처럼 이어 물어도
  이전 대화를 그대로 AI에 전달합니다. 0.4.x에서는 검색·화면 답변 뒤의 대화를
  정규식 판단에 따라 잘라냈습니다.
- **검색 강제는 직접 요청할 때만.** `검색해 줘`, `찾아줘`, `사실 확인해 줘`,
  `출처와 함께` 같은 직접 요청이나 `🔍`(모바일 `⌕ 검색`) 버튼, 후속 탐색 칩만
  검색을 강제합니다. 최신·가격·비교·추천 같은 주제어나 화면 첨부만으로는 강제하지
  않고, 검색 도구를 열어 둔 채 AI가 필요할 때 사용합니다. `검색 엔진 최적화 글 써줘`,
  `원문에서 오타 찾아줘` 같은 글쓰기 요청은 검색을 강제하지 않습니다.
  `검색하지 말고`처럼 금지하면 검색 도구 자체를 빼며, 이 금지가 버튼보다 우선합니다.
- **출처가 없을 때.** 검색을 직접 요청했는데 출처를 받지 못하면 다른 AI로 한 번 더
  시도하고, 그래도 없으면 오류 대신 `웹 출처를 확인하지 못한 답변` 표시와 함께
  답변을 보여 줍니다. 출처는 공급자가 돌려준 실제 링크만 최대 6개 표시합니다.
- **적용 확인.** 검색·화면 자료가 섞인 대화에서 AI가 원문·상황·결과 변경, 완성하기,
  복사, 새 글 같은 동작을 제안하면 바로 실행하지 않고 변경 미리보기와 `적용`/`취소`
  카드를 보여 줍니다. 화면 이동(기록·설정 열기, 이전·다음 결과 등)은 바로 실행합니다.
  외부 자료가 없는 대화의 명시적 요청은 이전처럼 바로 실행합니다.
- **진행 표시와 중단.** 답변을 기다리는 동안 `답변을 준비하는 중`, `웹에서 찾아보는 중`,
  `다른 AI로 다시 시도하는 중`과 경과 시간을 보여 주고, 보내기 버튼이 `중단`으로
  바뀝니다. 중단하면 진행 중인 연결을 끊고 입력한 메시지를 입력칸에 되돌립니다.

- 공통 계약·기억 정책: 39개 테스트 통과
- Windows: 111개 테스트, 글 강화기 화면 10종·사이드 채팅 3종·0.5.0 신규 화면 2종
  (적용 확인 카드, 진행 표시와 중단 버튼) QA 캡처, ZIP 실추출·무결성·두 창 직접
  실행 스모크 통과
- Android: 68개 debug 단위 테스트 통과, lint 이슈 0개, debug APK 빌드와 v2 서명 확인
- 0.5.0의 검색 판단, 후속 질문 맥락 유지, 적용 확인, 출처 없음 처리, 중단, 진행 알림은
  모의 응답 자동 테스트로 확인했습니다. 실제 API 네트워크 호출과 Android 실기기의
  새 화면(⌕ 검색·중단·적용 카드)은 이번에 확인하지 못했습니다.

0.4.x에서 확인한 항목:

- 연결된 기기에 저장된 API 키로 최초 강화와 사이드 채팅 네트워크 실호출을
  확인했습니다. 공급자 자동 폴백은 모의 응답 테스트 범위입니다.
- 연결된 Android 실기기에서 스와이프 시 키보드 비활성, 명확한 탭 입력,
  길게 누른 선택 유지, 편집 메뉴 재터치 접기·뒤로가기 상태 유지, 보조 입력의
  편집·음성 도구 비노출, 작은 창의 고정 주요 버튼과 창 크기 조절을 확인했습니다.
